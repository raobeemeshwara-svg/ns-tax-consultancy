# NS Tax Consultancy – Website

Taxation and Accounting Advisory Services · Utla Nagasrinivasulu

## Folder structure
```
index.html
style.css
script.js
README.md
images/
  nagasrinivasulu.jpg   <- add the photo here (exact name)
```

## Deploy
1. Create a GitHub repository and upload all files, plus an `images` folder containing the photo.
2. Host on Google: Firebase Hosting (`firebase init hosting`, public directory `.`, then `firebase deploy`) or any static host connected to the repo.

## Edit settings
Phone numbers, number of weekends shown and time slots are at the top of `script.js`.
